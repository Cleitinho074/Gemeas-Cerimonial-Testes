Como a cerimonialista se liga a várias contas

Hoje o sistema já tem conta → evento → convidado (uma conta com vários eventos, a RN06). O que falta é a tabela de relação cerimonialista_conta: é ela que permite uma cerimonialista atender várias contas diferentes, e uma mesma conta ter mais de uma cerimonialista (a titular e uma assistente, por exemplo). O vínculo dá permissão de leitura — quem edita a lista continua sendo a noiva.

cerimonialista ──┐ │ cerimonialista_conta (N:N) ├──── id ├──── cerimonialista_id FK → cerimonialista ├──── conta_id FK → conta ├──── papel 'cerimonialista' | 'assistente' ├──── vinculado_em data └──── status 'ativo' | 'encerrado' conta ───────────┘ └── evento (1:N) ← RN06, já existe └── convidado (1:N)

A consulta do painel percorre esse caminho: cerimonialista → contas vinculadas → eventos dessas contas → convidados de cada evento. Neste protótipo o resultado já está pronto em EVENTOS, dentro de js/cerimonial.js.
